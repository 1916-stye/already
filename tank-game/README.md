# 星域防线 · 坦克大作战

这是一个不依赖框架、不依赖外部网络资源的 2D 坦克游戏第一版。提交文件夹后，直接打开 `index.html` 即可运行；也可以把整个 `tank-game` 文件夹部署到任意静态网页空间。

## 当前版本

- 单人、双关卡、俯视角战场
- 原创大厅模式选择：普通模式、挑战模式、Boss 模式和无尽模式
- WASD / 方向键移动（同时调整炮管朝向），空格、点击画布或右上角“发射”按钮开火
- 砖墙、钢墙、水域、基地和敌方坦克
- 得分、生命、敌军数量、暂停、胜利和失败反馈；结算页显示总分、完成关卡和用时
- 手机端横屏优先，左下移动方向键、右侧独立瞄准摇杆与发射按钮
- 两关难度递进：侦察型、标准型、重装型三种敌人；第二关加入关底指挥官 Boss，重装敌人和 Boss 都需要多次命中
- 命中判定覆盖子弹完整轨迹，并提供命中、击破和子弹轨迹反馈
- 使用浏览器原生 Web Audio 生成轻量发射、命中、爆炸、Boss 和通关音效；可随时关闭，不自动播放
- 无尽模式按波次刷怪，波次越高敌人数量、速度和生命值会逐步提升，并在结算页保留总分与坚持波数
- 各模式会在浏览器本机保存最佳成绩，不上传、不跨设备同步
- 移动方向与炮口方向分离，支持 360° 瞄准；松开瞄准摇杆后保留上次炮口方向
- 所有脚本和样式均为本地文件，暂不使用音乐，避免授权和加载问题

## 文件结构

```text
tank-game/
├─ index.html
├─ css/style.css
├─ js/
│  ├─ config.js       配置
│  ├─ input.js        键盘、鼠标、触摸输入
│  ├─ collision.js    碰撞基础方法
│  ├─ map.js          地图和墙体绘制
│  ├─ entities.js     坦克与子弹实体
│  ├─ game.js         游戏循环、规则和状态
│  └─ main.js         页面按钮与移动端控件
└─ README.md
```

## 参赛前检查

1. 在没有开发环境的电脑上直接双击 `index.html`。
2. 断开网络后重新打开，确认仍可运行。
3. 用手机浏览器访问部署后的网址，横屏测试移动控制。
4. 重点记录手机端“移动—瞄准—发射—命中”是否顺手，并确认第一关到第二关、Boss 和最终结算流程完整。
